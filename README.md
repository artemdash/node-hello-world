# Node.js Hello World

A minimal Node.js app for testing Node.js hosting.

## What it does

- `/` shows a "Hello, World!" page with the Node.js version, port and host name.
- `/health` returns `{"status":"ok"}`.

## Deploy in cPanel (Meridian)

1. Open **Websites**, then **Web Apps**.
2. Choose **Deploy from Git** and enter the repository URL.
3. Select a domain and click **Deploy**.
